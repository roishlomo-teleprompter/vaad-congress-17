# קבקליק - מקור משותף לאנדרואיד ול-iOS

זהו עותק פרטי חדש. לא בוצעו Commit, Push, פריסה לאתר או העלאה לחנות.

## פתיחה במק

חלץ את KabClick-Unified-Source.zip לשולחן העבודה. נוצרה תיקייה חדשה בשם KabClick-Unified.

```bash
cd "$HOME/Desktop/KabClick-Unified"
bash Prepare-Mac.command
```

הסקריפט מתקין את התלויות המדויקות, מריץ בדיקות, מסנכרן את הקוד ל-iOS ופותח את Xcode. הוא אינו יוצר Archive ואינו מעלה דבר.

ב-Xcode בחר סימולטור ולחץ Run. בדוק התחברות, כותרת ומגרעת, כל חמשת שלבי הקבלה, כפתורי תחתית, פתיחת גיליון ו-Drive, הפקת קבלה ושיתוף PDF. בדוק גם בעת פתיחת המקלדת וסגירתה.

הגדרות Google של העותק מהמק, Bundle ID, Team ופרופיל החתימה נשמרו. תעודות ומפתחות פרטיים אינם בחבילה: הם נשארים ב-Keychain במק. במק אחר צריך להגדיר חתימה בהתאם לחשבון.

## פתיחה ב-Windows לאנדרואיד

חלץ לתיקייה חדשה, למשל C:\projects\Kabclick\KabClick-Unified. אל תחלץ מעל פרויקט ייצור קיים.

```powershell
cd C:\projects\Kabclick\KabClick-Unified
powershell -ExecutionPolicy Bypass -File .\Prepare-Android.ps1
npm run open:android
```

לחלופין הרץ npm ci, אחריו npm test ואז npm run sync:android. Android Studio יגדיר SDK מקומי. נדרש JDK 21. קובץ local.properties וקובצי חתימה מהמחשב הקודם אינם כלולים.

## עבודה שוטפת - מקור אחד

- את המסכים והלוגיקה המשותפים עורכים רק ב-www/index.html.
- ב-www/native-adapter.js יש גשר משותף לרכיבים המקוריים, עם תנאים מפורשים ל-iOS בלבד.
- www/ios-native.css נטען רק ב-iOS. הוא מכיל את תיקוני המגרעת, גובה האשף, כפתורי התחתית וגודל שדות הקלט מהעותק שנבדק במק.
- www/google-bootstrap.js משתמש ב-iOS בתקשורת המקורית ל-Google. באנדרואיד ובדפדפן הוא טוען את אותן ספריות Google שבהן השתמשה גרסת Android.
- תיקיות ios ו-android מכילות את הרכיבים והחתימה של המערכת המתאימה.
- אין לערוך את ios/App/App/public או android/app/src/main/assets/public: אלה עותקים שנוצרים בסנכרון.

לאחר שינוי:

```bash
npm test
npm run sync:ios
```

או באנדרואיד:

```bash
npm test
npm run sync:android
```

הפקודות בוחרות את App ID של המערכת. אין להריץ cap sync ללא בחירת מערכת. כדי לסנכרן לשתיהן, הרץ את שתי פקודות הסנכרון אחת אחרי השנייה.

## מה נבדק

עברו תשע בדיקות הרגרסיה הקיימות, בדיקת הפרדה בין פלטפורמות ובדיקת תקשורת Google עם תשובות מדומות. בדיקת ההפרדה משווה את קובץ Android המקורי, כולל כל העיצוב והלוגיקה העסקית, למקור המשותף אחרי הסרת נקודות ההתאמה המפורשות ומספר ה-Build. בנוסף נבדקו 40 קובצי מקור ומשאבי Android, והתמונות והקבצים המשותפים.

כל 28 הצהרות העיצוב האפקטיביות של iOS הושוו לעותק מהמק ונשמרו. פרטי OAuth, קוד Swift, storyboards והגדרות חתימת Apple נשמרו. הסנכרון לשתי המערכות הצליח, והעתקי הנכסים בשתי המערכות זהים למקור www.

בנייה מלאה של Android לא הושלמה בסביבת ההכנה: חסמו הורדת תלויות Gradle, והתלויות לא נמצאו במטמון. אין Xcode בסביבת ההכנה ולכן לא בוצעה כאן קומפילציית iOS. אין בחבילה APK, AAB או IPA חדשים.

בדיקות הקוד אינן מחליפות בדיקה אמיתית על Android ו-iPhone. לפני פרסום יש להשלים את תהליך הבדיקות הרגיל, כולל Google, Drive, Sheets, מספור, יצירת PDF, שמירה וסנכרון, ולוודא שאין גלישה או כפתורים חתוכים.

יש אזהרה מכוונת במבחן שחזור כשל העברת תיקייה. היא חלק מהמבחן, ומסתיימת ב-PASS כאשר השחזור תקין.

## שמירת הפרטיות והגרסאות הקודמות

החבילה אינה מחליפה את תיקיית המק הישנה או את פרויקט Android הקיים. שמור אותם עד סיום בדיקות שתי המערכות. לא נכללו node_modules, תוצרי בנייה, לוגים, תיקיות גיבוי, תעודות או מפתחות חתימה. נדרשת גישה לאינטרנט להתקנת התלויות ולשירותי Google; "פרטי" אינו אומר שהפעילות מול Google נעשית ללא אינטרנט.
